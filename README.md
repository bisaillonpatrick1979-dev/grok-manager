## Ouvrir maintenant (téléphone)

1. GitHub → Settings → Pages → Source **Deploy from a branch** → `main` / `/ (root)` → Save
2. Attends 1 min, ouvre :
   https://bisaillonpatrick1979-dev.github.io/grok-manager/

Sinon : télécharge le repo (Code → Download ZIP), ouvre `index.html` dans Chrome.
