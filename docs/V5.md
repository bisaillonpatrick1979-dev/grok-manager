# v5 Récompenses

Admin crée un objectif par chantier, employé ou sous-traitant.
Métrique : heures punchées ou pi².
Prix : souper d'équipe, tirage d'outil (registre), bonus, journée off.
Barre de progression. Quand c'est atteint : Remettre le prix / Tirer un outil.
Employés voient leurs défis + les défis chantier.
